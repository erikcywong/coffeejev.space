02 / BOUNDARY & FUNCTIONAL UNIT

边界与功能单位：纳入了什么，以及每一项排除的理由

cradle-to-gate · ISO 14067 / PAS 2050 aligned · GHG Protocol scopes

系统边界为 cradle-to-gate：从上游投入品生产、育苗车间运行，到苗出厂交付（门到门含外运）为止，不含种植端成株阶段、不含消费者使用、不含最终处置。 Scope 1 / 2 / 3 按 GHG Protocol 划分；排除项一律给出可审计的排除理由，而不是"暂不计入"。

2.2 纳入 / 排除清单 scope inventory

项目Scope纳入计量来源 / 因子理由
已纳入 · INCLUDED
外购电力（雾化泵、LED、除湿、网关、控制柜）Scope 2纳入power-meter-PuEr-01 的 kwh_total 逐区间差分 × 六段 MEF占总量 61.4%，计量级一次数据，是全部论点的地基
氮肥（营养盐）Scope 3 · cat 1纳入加肥泵配液记录累加 N 质量 × 13.5 kgCO2e/kg N占 4.2%；硝酸盐生产的能耗与 N2O 前体，是雾培唯一显著的农资投入
包装（苗盘、护根、外箱）Scope 3 · cat 5纳入0.012 kgCO2e/株 × 实际出库套数占 6.2%；可回收周转箱方案实施后应下降，需按实际采购单更新
外运（出厂到客户）Scope 3 · cat 4纳入0.020 kgCO2e/株（常温干线，吨公里法）占 10.3%；若改冷链需 ×1.6 待核证，现方案为常温
嵌入式硬件摊销（8 台设备）Scope 3 · cat 2纳入整机上游制造排放 ÷ 4 年 ÷ 年出苗量，折 0.035 kgCO2e/株占 18.0%；专用资产可归属到批次，若不摊则硬件投入在账上"免费"，属系统性低估
排除 · EXCLUDED（含理由）
育苗基质（泥炭/椰糠）Scope 3排除—气雾栽培不使用基质，物理上不存在该排放源。注意：该差异会体现在基线而非本项目，见 §6.3
Scope 1（备用柴油发电机、制冷剂补充）Scope 1未量化维保记录（尚未结构化）无常规燃烧源；制冷剂年补充 <0.5 kg/室，分摊 <0.5%，低于 1% 截断阈值。按 14067 需在报告中列为截断项
自来水 / RO 供水Scope 3 · cat 1排除—供水与 RO 能耗 <1% 总量，按截断规则排除；已计入敏感性分析上界（+0.004）
厂房与土建（资本货物）Scope 3 · cat 2排除—共享资产，无法按批次归属；与硬件设备的区别在于可归属性，不在排量大小。属方法学选择，已披露
土地利用变化（LUC）Scope 3排除—育苗场地为既有农业用地，无 LUC 发生；若扩产占用林地须重新评估。基线侧泥炭开采的 LUC 不在此边界内，见 §6
生物源 CO2（植株光合吸收）—排除—按 ISO 14067，生物源碳的吸收与短期储存不计入产品碳足迹，也不得用于冲抵。苗不是碳汇，不得如此宣传
员工通勤 / 办公 / 差旅Scope 3排除—<1% 且与产品无物理关联，按截断规则排除；不得在营销材料中据此声称"边界完整"

截断规则：单项 < 总量 1% 且累计 < 5% 的排放源可排除（PAS 2050 惯例）。本页排除项累计约 1.5%，其中 Scope 1 未量化为数据缺口而非截断判断，须在核证前补维保台账。
